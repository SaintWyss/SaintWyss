## Trabajo destacado

### SME Cyber

Plataforma web para producir assessments, scoring y reportes técnicos o ejecutivos de ciberseguridad.

- Python, FastAPI, SQLAlchemy, Alembic, React, TypeScript y Tailwind CSS.
- Persistencia compatible con SQLite y PostgreSQL.
- Recomendaciones asistidas por Gemini o Claude sin delegar el cálculo del riesgo al modelo.
- Arquitectura modular, trazabilidad de resultados y separación entre dominio e infraestructura.

### RAG Corp

Plataforma RAG empresarial orientada a organizaciones, seguridad y evaluación reproducible.

- Ingesta documental, embeddings, búsqueda híbrida, reranking y respuestas con citas.
- Organizaciones, miembros, RBAC, MFA, SSO, API keys y webhooks.
- FastAPI, Next.js, PostgreSQL, pgvector, Redis y almacenamiento de objetos.
- Observabilidad, límites defensivos, auditoría y evaluación de calidad.

### Wyss

Asistente personal multi-dispositivo para automatizar computadoras, servicios y rutinas.

- Motor determinístico con soporte opcional para modelos de lenguaje.
- Memoria, rutinas, resumen diario, Notion, n8n, PWA y aplicación Android.
- Confirmaciones obligatorias y recuperación para operaciones sensibles.
- Separación entre planificación, política, ejecución y verificación.

## Cómo diseño sistemas

1. Mantengo la lógica crítica fuera de modelos de lenguaje y proveedores externos.
2. Diseño autorización, validación, límites y auditoría desde el inicio.
3. Distingo entre implementado, probado, validado parcialmente y pendiente.
4. Uso métricas, pruebas y evidencia antes de afirmar que una capacidad está lista.
5. Documento arquitectura, decisiones, configuración, operación y recuperación.
